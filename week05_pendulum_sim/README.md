## 五、物理背景

单摆的真实运动方程（非线性）：

```
d²θ/dt² = -(g / L) · sin(θ)
```

其中 `θ` 为摆角（弧度），`L` 为摆长（米），`g` 为重力加速度（9.81 m/s²）。

当摆角很小时（`θ < 约 15°`），可用**小角度近似** `sin(θ) ≈ θ` 简化为：

```
d²θ/dt² = -(g / L) · θ
```

此时单摆做简谐振动，周期为 `T = 2π√(L/g)`。

> 本实验**不采用**近似，直接对非线性方程做数值积分，因此能观察到大角度下
> 周期变长的真实物理现象。

## 六、运行方式

### 方式一：浏览器交互版（推荐先玩这个）

直接用鼠标**双击** `web/index.html`，浏览器里就会看到一个会左右摆动的单摆。

无需安装任何东西，无需命令行，不需要联网。

**交互功能**：

| 操作 | 效果 |
| :--- | :--- |
| 拖动「摆长 L」滑块 | 改变绳长，周期随之变化（L 越长摆得越慢） |
| 拖动「重力 g」滑块 | 模拟不同星球的重力（g 越小摆得越慢） |
| 拖动「初摆角」滑块 | 改变起始角度，松手后按新角度重新释放 |
| 点击画布任意处 | 直接把点击方向设为新的起始摆角 |
| 「重新释放」按钮 | 从初始摆角重新开始 |
| 「暂停」按钮 / 空格键 | 冻结 / 恢复动画 |
| 按 R 键 | 重置 |

### 方式二：Python 命令行版

```bash
cd week05_pendulum_sim
python src/pendulum.py
```

运行后，结果数据会写入 `results/` 目录。

> 两个版本使用**完全相同的物理模型与数值算法**（四阶龙格-库塔法），
> 区别只在于一个输出 CSV 数据、一个用 Canvas 画成动画。
