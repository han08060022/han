## 五、物理背景

单摆的真实运动方程（非线性）：

```
d²θ/dt² = -(g / L) · sin(θ)
```

其中 `θ` 为摆角（弧度），`L` 为摆长（米），`g` 为重力加速度（9.81 m/s²）。

当摆角很小时（`θ < 约 15°`），可用**小角度近似** `sin(θ) ≈ θ` 简化为：

```
d²θ/dt² = -(g / L) · θ
```

此时单摆做简谐振动，周期为 `T = 2π√(L/g)`。

> 本实验**不采用**近似，直接对非线性方程做数值积分，因此能观察到大角度下
> 周期变长的真实物理现象。
