## 三、实验步骤与代码

**核心思路**：单摆的真实运动方程是 `d²θ/dt² = -(g/L)·sin(θ)`，
无法直接求出解析解，因此采用**四阶龙格-库塔法（RK4）**做数值积分。

关键代码（`src/pendulum.py`）：

```python
def derivatives(theta, omega, length):
    dtheta = omega
    domega = -(G / length) * math.sin(theta)   # 完整非线性方程
    return dtheta, domega
```

RK4 每次推进时取四个斜率加权平均，精度远高于简单欧拉法：

```python
k1t, k1o = derivatives(theta, omega, length)
k2t, k2o = derivatives(theta + 0.5*dt*k1t, omega + 0.5*dt*k1o, length)
k3t, k3o = derivatives(theta + 0.5*dt*k2t, omega + 0.5*dt*k2o, length)
k4t, k4o = derivatives(theta + dt*k3t,     omega + dt*k3o,     length)
theta += (dt/6.0) * (k1t + 2*k2t + 2*k3t + k4t)
omega += (dt/6.0) * (k1o + 2*k2o + 2*k3o + k4o)
```

周期测量采用**同向过零点**法：只统计摆球每次都从同一侧穿过平衡位置的时刻，
相邻两次之间即为一个完整周期。

## 四、实验结果与分析

摆长 L = 1.0 m，仿真时长 10 s，时间步长 0.001 s：

| 初始摆角 | 仿真周期 (s) | 理论周期 (s) | 相对偏差 |
| :---: | :---: | :---: | :---: |
| 5° | 2.0070 | 2.0061 | +0.05% |
| 15° | 2.0147 | 2.0061 | +0.43% |
| 45° | 2.0863 | 2.0061 | +4.00% |
| 90° | 2.3678 | 2.0061 | +18.03% |

**分析**：

1. **小角度时吻合极好**。5° 时偏差仅 0.05%，说明在此范围内 `sin(θ)≈θ`
   的近似高度成立，单摆可视为严格的简谐振动。
2. **摆角增大，周期单调变长**。45° 时偏差 4%，90° 时飙升到 18%。
   这是非线性效应：`sin(θ) < θ` 恒成立，摆角越大两者差距越大，回复力相对
   减弱，摆球"回来得更慢"，于是周期变长。
3. **结论**：理论公式 `T = 2π√(L/g)` 只在**小角度**下成立，常规教学中
   通常约定摆角小于 15° 才可使用。

## 五、遇到的问题与解决过程

**问题**：第一版代码算出的周期全部是理论值的 **2 倍**（5° 时算出 4.0140 s）。

**排查**：检查周期测量逻辑，发现过零点全部混在一起统计了——
"正→负"和"负→正"两类过零被交替记录，相邻两点之间其实只有**半个周期**。

**解决**：改为只保留「由正变负」这一类过零点，相邻两点之间才是完整周期。
修正后 5° 偏差从 +100.10% 降到 +0.05%，与理论值高度吻合。

> 这次调试的教训：物理量测量要先做**量纲和数量级自检**。
> 一个 2 倍的偏差，往往不是数值精度问题，而是定义层面的错误。
